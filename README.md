# TrendVolt

A modern full-stack fashion e-commerce platform built with React, Node.js, Express, MongoDB, Razorpay, Cloudinary, and n8n.

## 🚀 Overview

TrendVolt is a full-stack fashion e-commerce web application designed with a modern, premium shopping experience.

The project includes user authentication, product browsing, cart management, secure checkout, image management, and automated order notifications.

## ✨ Features

- Modern fashion-focused e-commerce UI
- User registration and login
- JWT-based authentication with HTTP-only cookies
- Product browsing and product details
- Category-based fashion products
- Cart management
- Backend-controlled product pricing and stock validation
- Secure Razorpay payment integration
- Cloudinary image management
- Automated order notifications using n8n
- Customer order confirmation emails
- Admin order notifications
- Responsive design for desktop and mobile
- Protected API routes
- Environment-based configuration

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cookie-based Authentication

### Integrations

- Razorpay — Payment processing
- Cloudinary — Image storage and management
- n8n — Order notification automation
